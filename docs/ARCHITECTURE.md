# AIkefu 智能在线客服云平台架构设计规范 (System Architecture)

本项目为自研的企业级全渠道 **AI 智能在线客服云平台 (AIkefu)**。打通 Web、Windows 桌面端与移动端交互，具备毫秒级打字实时预知、全流程访客雷达与轨迹追踪、SaaS 多租户隔离、专属企业知识库 (RAG & FAQ) 及 AI 7×24 小时自动托管与人机无缝协同能力。

## 二、核心模块职责与设计

### 1. 多租户数据引擎 (`server/store.js`)
* **租户隔离**：每个企业客户在注册后拥有全局唯一 `tenantId` 和 `appKey`；
* **7 天全功能试用**：注册即刻赠送 7 天免费试用期与 50,000 Token 体验积分；
* **按量计费与预测模型**：根据近 7 天日均咨询量，自适应评估积分剩余可用天数。

### 2. AI 智能托管与 RAG 知识库检索 (`server/ai-service.js`)
* **企业知识库匹配**：访客提问时，基于关键词交叉检索召回最相关的 FAQ 知识条目；
* **双核大模型驱动**：支持标准 OpenAI 兼容大模型（DeepSeek、通义千问、智谱等）及高精准本地语义规则库双模运行；
* **Token 消耗原子核算**：按实际消耗精准扣除租户积分。

### 3. 实时通信与人机协同网关 (`server/index.js`)
* 基于 WebSocket 实现毫秒级消息推送；
* 访客打字实时预知上报；
* 访客触发“转人工”或坐席点击“一键接管”时，状态平滑流转。

### 4. 商业结算支付中心 (`server/payment-service.js`)
* 支持 **微信 Native 扫码支付** 与 **PayPal 国际支付**（收款账号 `181827969@qq.com`）；
* 订单完成自动激活 199 元人工年费套餐或充值对应 Token 积分。
