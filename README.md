# AIkefu (智能云客服) SaaS 多租户与 AI 在线客服云平台

本项目基于 **REA (Reverse Engineer Anything)** 的系统架构与重构设计理念，对行业知名在线客服系统 **[AIkefu (智能云客服)](https://www.aikefu.com/)** 进行了 1:1 深度自研实现与现代全栈升级，并重构为面向商业化运营的 **SaaS 多租户 AI 智能在线客服云平台**。

---

## 一、SaaS 商业模式与核心特性

### 1. 7 天免费试用体系
* **自助注册开通**：任何企业或个人访问 `http://127.0.0.1:8080/console/` 注册，系统自动开通 **7 天全功能免费试用**；
* **赠送体验积分**：注册即赠 **50,000 Token 体验积分**（可体验约 100~200 次真实 AI 问答交互）；
* **专属 AppKey 隔离**：每个租户分配独立 `appKey`，支持一行代码接入：
  ```html
  <script src="http://127.0.0.1:8080/widget.js?appKey=您的AppKey"></script>
  ```

### 2. 商业收费套餐体系
* **套餐 A：人工在线客服标准版（199 元/年）**
  * 包含多坐席接待、Windows 原生客户端、访客打字实时预知、全站访客雷达与常用话术双击秒发，无 AI 算力积分消耗。
* **套餐 B：AI 智能托管 Token 积分加油包**
  * 积分与 Token 1:1 锚定，提供 10万、50万（79元）、200万（249元）等按量积分包；
  * **积分智能消耗与可用时长预测引擎 (Burn-rate Estimator)**：系统根据近 7 天日均咨询量，在控制台实时评估并展示：`💡 预计当前积分还可支撑使用约 X 天`；
  * 积分耗尽自动平滑降级为“呼叫人工”或“离线留言”，确保访客沟通链路永不中断。

### 3. 每个租户独立 AI 人设与知识库 (FAQ & RAG)
* **个性化企业人设**：自定义客服昵称（如“小智”）、头像、欢迎语、System Prompt；
* **专属知识库录入**：租户可录入专属产品价格、发货快递、退换货政策、售后答疑等 FAQ 问答对；
* **RAG 智能组装应答**：访客提问时，AI 严格依知识库作答，杜绝幻觉；
* **平滑转人工与一键接管**：访客输入“人工/投诉”自动转人工，坐席可随时**一键接管**或**交还 AI 托管**。

## 三、一键启动与使用方式

在项目根目录下双击运行：
* [**`start-all.bat`**](start-all.bat) 或 [**`start-all.vbs`**](start-all.vbs)
脚本会自动拉起后台服务端、Windows 客服坐席端与访客端演示页面。

## 四、核心功能测试流程

1. **测试知识库与 AI 智能应答**：
   - 打开控制台 `http://127.0.0.1:8080/console/`，在“专属知识库”中添加一条问答；
   - 打开访客端 `http://127.0.0.1:8080/demo.html` 发起咨询，提问对应问题；
   - 观察 AI 客服秒速回复，并带有 `🤖 AI 智能解答` 标识；
   - 返回控制台看板，观察积分扣减与可用天数预估动态更新。
2. **测试转人工与一键接管**：
   - 访客在聊天窗口点击右上角【👨‍💼 转人工】或输入“转人工”；
   - 客服坐席端（`1001`）收到接入提示；
   - 坐席点击【🤖 一键接管会话】接棒沟通，沟通完毕可点击【🤝 交还 AI 托管】恢复自动值守。
