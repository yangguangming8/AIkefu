# iBangKF (爱邦客) 在线客服系统全套复刻方案

本项目基于 **REA (Reverse Engineer Anything)** 的逆向工程与重构设计理念，对行业知名在线客服系统 **[iBangKF (爱邦客)](https://www.ibangkf.com/)** 官方 Windows 安装包及通信协议进行了深入二进制分析，并完成了**高性能服务端 (Server)**、**Windows 客服坐席桌面客户端 (Windows Client)**、**全功能网站访客端 (Visitor Widget SDK)** 与**演示网站**的全套 100% 自研复刻与现代架构升级。

---

## 一、逆向工程成果 (Reverse Engineering)

通过对爱邦客官方安装包 `ibangkf-setup.exe` 的解包与 Delphi 二进制字符串逆向，我们完整提取还原了其底层的业务状态机与通信协议：
* **核心协议指令集**：`UP_LOGIN`, `DOWN_LOGIN`, `DOWN_VISITOR_ADD`, `DOWN_VISITOR_ALL`, `DOWN_VISITOR_CALL`, `DOWN_VISITOR_PREMSG`, `DOWN_VISITOR_MSG`, `DOWN_VISITOR_CHANGE_PAGE`, `DOWN_VISITOR_SEARCHWORD`, `DOWN_VISITOR_TRANSFER`, `DOWN_VISITOR_ENDCHAT` 等。
* **核心业务逻辑**：详细分析报告见 [`docs/REVERSE_ENGINEERING.md`](docs/REVERSE_ENGINEERING.md)。

## 二、系统三大核心模块

### 1. 服务端 (Server - Node.js + Express + WebSocket)
* **实时网关**：毫秒级全双工 WebSocket 长连接，支持坐席与访客会话路由、状态广播、智能负载分流。
* **业务引擎**：包含访客实时轨迹监控、来源搜索词提取、黑名单、离线留言、常用话术分类管理。
* **轻量化数据存储**：内置持久化存储，**零外部庞大数据库依赖**，直接开箱即用。

### 2. Windows 客服坐席端 (Windows Client)
* **独立桌面窗口体验**：支持 Windows 原生独立桌面运行，无浏览器多余边框与干扰。
* **三栏式专业工作台**：
  * **左栏**：正在对话列表（带未读红点）、全站访客雷达（实时监控浏览本站的所有访客）、离线留言板、历史会话归档。
  * **中栏**：会话消息流、**【访客打字实时预知横条】**（访客正在打字未发送，坐席端已提前毫秒级同步预览）、快捷工具条（表情、图片上传、清屏）、多行编辑输入区。
  * **右栏**：访客全景画像（IP、城市、来源网站、搜索词、访问轨迹时间轴）、分类常用话术库（**单击填入输入框，双击直接发送**，支持坐席动态添加话术）。
* **通知与声音体系**：内置 Web Audio 高拟真“叮咚”新消息音效与“水滴”访客上线音效，支持系统托盘闪烁与通知。

### 3. 访客端挂件 SDK 与演示网站 (Visitor Widget & Demo)
* **一行代码接入**：任何网站只需添加一行代码 `<script src="http://127.0.0.1:8080/widget.js"></script>`，右下角即刻自动生成浮动客服按钮。
* **轨迹与预知上报**：访客在页面间跳转、在输入框中打字，均实时上报给客服坐席端。
* **兜底能力**：坐席全忙或离线时，自动切换为优雅的离线留言表单。

## 三、快速开始与一键启动

### 方式 1：一键全自动启动（推荐）
在项目根目录双击执行：
```bash
start-all.bat
```
该脚本会自动：
1. 启动后台服务端（监听 `8080` 端口）；
2. 启动 Windows 客服坐席独立桌面客户端，自动定位到客服登录台；
3. 打开访客端模拟测试网站 `demo.html`。

### 方式 2：单独启动各个组件
* **启动服务端**：
  ```bash
  start-server.bat
  # 或在 server 目录下运行: node index.js
  ```
* **启动 Windows 客服坐席端**：
  ```bash
  start-windows-client.bat
  # 也可以在浏览器中直接打开: http://127.0.0.1:8080/agent/index.html
  ```
* **打开访客模拟演示站**：
  在浏览器访问：`http://127.0.0.1:8080/demo.html`

## 五、重点体验：杀手级功能测试清单

1. **测试【访客打字实时预知】**：
   - 打开 Windows 客服客户端，用 `1001` 登录；
   - 打开 `http://127.0.0.1:8080/demo.html`，点击右下角客服图标发起咨询；
   - 在访客输入框中随意打字（**注意：先不要按回车发送**）；
   - 切换到 Windows 客服端，你会发现输入框上方立即高亮显示：`🔍 访客正在输入：[你刚打的字]`！
2. **测试【全站访客实时雷达与主动邀请】**：
   - 访客在演示网站中点击“解决方案”、“产品定价”等不同菜单；
   - 客服端左侧切换至“访客监控”，即可实时看到该访客当前停留在哪个页面；
   - 客服点击“主动邀请”，访客屏幕上立即弹出专属客服对话框！
3. **测试【快捷常用话术双击直发】**：
   - 在客服端右侧展开“常用话术”，找到任意一条回复，**双击**该话术，直接秒发至访客窗口！
