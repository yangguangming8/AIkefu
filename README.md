# AIkefu (智能云客服) SaaS 多租户与 AI 在线客服云平台

AIkefu 是一款面向企业与个人站长的高性能、多租户 **SaaS 在线客服与 AI 智能托管系统**。系统融合了传统即时客服的极致实时性（WebSocket 双向通信、访客打字实时预知、全站轨迹监控）与现代大模型 AI 的自主解答能力，支持微信支付、PayPal 国际结算、多租户数据完全隔离与自定义专属知识库。

---

## 一、SaaS 商业模式与核心特性

### 1. 7 天免费试用体系
* **自助注册开通**：任何企业或个人访问 `http://127.0.0.1:8080/console/` 注册，系统自动开通 **7 天全功能免费试用**；
* **赠送体验积分**：注册即赠 **50,000 Token 体验积分**（可体验约 100~200 次真实 AI 问答交互）；
* **专属 AppKey 隔离**：每个租户分配独立 `appKey`，支持一行代码接入：
  ```html
  <script src="http://127.0.0.1:8080/widget.js?appKey=您的AppKey"></script>
  ```

### 2. 商业收费套餐体系
* **套餐 A：人工在线客服标准版（199 元/年）**
  * 包含多坐席接待、Windows 原生客户端、访客打字实时预知、全站访客雷达与常用话术双击秒发，无 AI 算力积分消耗。
* **套餐 B：AI 智能托管 Token 积分加油包**
  * 积分与 Token 1:1 锚定，提供 10万、50万（79元）、200万（249元）等按量积分包；
  * **积分智能消耗与可用时长预测引擎 (Burn-rate Estimator)**：系统根据近 7 天日均咨询量，在控制台实时评估并展示：`💡 预计当前积分还可支撑使用约 X 天`；
  * 积分耗尽自动平滑降级为“呼叫人工”或“离线留言”，确保访客沟通链路永不中断。

### 3. 每个租户独立 AI 人设与知识库 (FAQ & RAG)
* **自定义人设**：租户可随时在控制台配置 AI 客服昵称、专属头像、欢迎语、系统 Prompt 提示词；
* **企业专属知识库**：支持租户自主维护常见问答库 (FAQ)，AI 回复优先精准命中企业知识，答不上来时礼貌引导转人工；
* **转人工触发词**：支持配置触发词（如“人工”、“投诉”、“退款”），命中后自动分流至在线人工坐席。

### 4. 双通道合规支付 (微信 Native 扫码 + PayPal)
* **微信支付**：生成 Native 扫码支付账单，支持轮询与异步回调履约；
* **PayPal 支付**：支持美元等国际货币结算，指定收款账号：`181827969@qq.com`；
* **自动化履约**：付款成功后系统秒级自动延长租户服务到期时间或增加 Token 积分。

## 二、生产级安全加固与体验完善

针对现代企业级在线客服安全与合规要求，系统已完成全面加固：
1. **密码安全与凭证防伪**：全面采用 `PBKDF2` 加盐哈希加密算法存储密码，登录颁发加密验签的真实 JWT Token；
2. **文件上传防御**：开启严格 MIME 与扩展名白名单拦截（仅放行 JPG/PNG/GIF/WEBP/PDF/DOC/DOCX/TXT/ZIP/RAR），坚决拦截 HTML/SVG 等同源 XSS 攻击；
3. **搜索引擎来源词解析**：支持百度 (`wd`/`word`)、搜狗 (`query`/`keyword`)、360 (`q`)、Google 与 Bing 的来源关键词精准提取并在客服端展示；
4. **单页应用 (SPA) 全轨迹捕捉**：深度劫持 `history.pushState` 与 `history.replaceState`，完美兼容 Vue、React、Angular 单页站点的无刷新路由跳转上报；
5. **访客身份持久化**：采用 `localStorage` 记忆访客身份，老访客刷新页面保持同一个名称与会话；
6. **5 星满意度评价体系**：会话结束或访客主动点击可唤起 1~5 星打分、快捷标签与评语面板，数据实时同步控制台与报表；
7. **黑名单防护机制**：坐席端支持“一键拉黑恶意访客”，系统即时终止会话并在 WebSocket 连接层拦截拉黑 IP 与访客；
8. **在线客服下拉平滑转接**：转接操作由手输工号升级为下拉选择当前在线客服列表并展示实时负荷；
9. **心跳保活与僵尸会话回收**：WebSocket 增加 30 秒 ping/pong 保活检测，后台定时任务每分钟自动清理 15 分钟无交互的离线会话并存盘归档，杜绝内存泄漏。

## 三、快速开始

### 1. 一键启动
双击运行根目录的 `start-all.bat`（或无控制台黑框的 `start-all.vbs`）：
* 服务端入口：`http://127.0.0.1:8080`
* 企业管理控制台：`http://127.0.0.1:8080/console/`
* 客服坐席工作台：`http://127.0.0.1:8080/agent/index.html`
* 访客接入测试演示页：`http://127.0.0.1:8080/demo.html`

### 2. 默认演示账号
* **企业管理员后台**：账号 `admin`，密码 `admin`
* **客服坐席工作台**：工号 `1001` 或 `1002`，密码 `123456`
